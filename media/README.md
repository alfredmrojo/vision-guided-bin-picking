# Showcase media

These figures and the trial excerpt accompany the [project case study](../README.md). The stills and plots come from the FEMTO-ST internship report. The silent animation is an excerpt from the original fixed-marker lab footage, reframed to show the robot, gripper and target.

The animation shows an individual physical trial. The screenshots in the case study illustrate the detection interface and planning preview; they are not frames from that recording. The depth trend plot is exploratory, while the quantitative table in the case study reports the selected correction configuration.
